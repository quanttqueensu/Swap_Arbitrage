# P33 position-sizing and risk verification

## Scope and versions

P33 adds the pure `strategy.position_sizing` and `strategy.risk_signals`
surface at `p33.position-sizing-risk.v1`; it preserves
`p10.strategy-equations.v1`. The public API exports, in order,
`MAX_RESIDUAL_FRACTION`, `SIZING_RISK_VERSION`, `VOLATILITY_LOOKBACK`,
`build_target_position`, `evaluate_risk`, `liquidity_scale`,
`scaled_target_dv01`, `signal_strength_scale`, and `volatility_scale`.
No P33 code reads files or a wall clock, estimates costs, or makes an external
connection. Bid/ask sizes and operational flags are caller-supplied causal
inputs. MG5 remains unapproved and P34 did not begin.

## Scale boundary evidence

The literal scale cases pass: 63 ordered prior values with median `0.8` and
current `1` give `0.8`; current `0.5` gives `1`; z-scores `0`, `1`, `2`, and
`-3` give `0`, `0.5`, `1`, and `1`; and quantities `10`, `-4` with displayed
sizes `5`, `4` give `0.5`. `3000 * 0.8 * 0.5 * 0.5` gives `600` USD/bp.
Malformed, non-UTC, reversed, future, short, long, nonpositive, nonfinite,
and wrong-type inputs return `None`; zero displayed size yields zero liquidity.

## Hand-checked hedge and capacity evidence

For traditional target `1000`, swap DV01 `100`, and Treasury DV01 `950`, P31
selects quantities `10`, `-1`, gross DV01 `1950`, residual net DV01 `-50`,
and residual fraction `0.05`; equality is allowed. Treasury DV01 `949.9`
produces fraction `0.0501` and returns no target. With current quantities
`4`, `-1`, the literal target has turnover `6`. Capacity limits reduce rather
than increase risk, and the regression `base=300`, `swap=100`,
`Treasury=63.4`, nonbinding sizes/caps/gross selects target `200` with
`within_capacity`, proving integer residual selection alone is not reported as
capacity scaling.

## Risk precedence and flatten evidence

Valid capacity scale `0.5` is allowed with `capacity_scaled`. Stale data
returns `stale_market_data`, zero scale, and requests emergency flatten only
for an open position. Explicit emergency beats scheduled and all later
failures; scheduled beats all later failures. Simultaneous hard failures retain
the tested order: stale data, invalid bid/ask, invalid market field, broker,
reconciliation, roll, session loss, drawdown, margin, residual, net DV01,
order rate, working orders. Explicit flatten without exposure leaves the
flatten request false while preserving its controlling `emergency` or
`scheduled` urgency.

## Known limitations and MG5 status

P33 is broker-independent and accepts caller-supplied capacities, operational
flags, and expected cost; it has no market-data, cost-model, broker, order, or
network integration. The frozen P33 configuration leaves the P10 economic
equations unchanged. MG5 is not approved, and no P34 work is included.
