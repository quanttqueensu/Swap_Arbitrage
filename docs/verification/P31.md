## Public functions and exact policies

| Function | Units and exact policy |
| --- | --- |
| `rate_decimal_to_bps(rate_decimal) -> Decimal | None` | Decimal rate to bps, multiplied by 10,000. |
| `treasury_fractional_quote_to_points(whole_points, thirty_seconds, eighths_of_32nd) -> Decimal | None` | Treasury points, with exact 1/256th conversion. |
| `tick_value_usd(minimum_increment_points, multiplier_usd_per_point) -> Decimal | None` | USD per tick, positive Decimal inputs only. |
| `fixed_swap_spread_bps(swap_rate_bps, treasury_rate_bps) -> Decimal | None` | Swap minus Treasury, in bps. |
| `funding_spread_bps(floating_rate_bps, repo_rate_bps) -> Decimal | None` | Floating minus repo, in bps. |
| `expected_funding_bps(consecutive_lagged_history_bps) -> Decimal | None` | Mean of the latest 60 lagged observations after the 40-observation warm-up. |
| `gross_excess_spread_bps(swap_spread_bps, expected_funding_bps) -> Decimal | None` | Fixed spread minus expected funding, in bps. |
| `directional_cost_buffer_bps(..., cost_base_dv01_usd_per_bp) -> Decimal | None` | Six nonnegative USD costs divided by positive USD/bp cost base. |
| `net_opportunity_bps(direction, gross_excess_bps, cost_buffer_bps) -> Decimal | None` | Traditional is gross minus cost; reverse negates gross then subtracts cost. |
| `dv01_hedge_quantities(direction, target_dv01, swap_dv01, treasury_dv01) -> tuple[int, int]` | Signed contract quantities; positive swap magnitude rounds half-away from zero with `ROUND_HALF_UP`. |
| `residual_dv01_usd_per_bp(swap_quantity, treasury_quantity, swap_dv01, treasury_dv01) -> Decimal | None` | Signed net DV01 is `-swap_qty*swap_dv01 - treasury_qty*treasury_dv01`, USD/bp. |
| `residual_fraction(net_dv01, target_dv01) -> Decimal | None` | Absolute residual divided by positive target DV01. |
| `basket_pnl_usd(legs, total_cost_usd) -> Decimal | None` | Signed point P&L less nonnegative total USD cost; every leg has an identical, full valid endpoint ID. |
| `contract_turnover_contracts(quantities) -> int | None` | Sum of absolute signed integer quantities, in contracts. |

All Decimal arithmetic that can round uses a local precision of 50.  The hedge
selector evaluates only floor and floor+1 Treasury candidates and orders ties
by `(absolute residual, gross DV01, Treasury quantity)`.  The 5% residual
boundary is an explicit caller policy (`fraction <= 0.05`), not a selector
override.  Inputs require exact finite `Decimal` values and exact `int`
quantities (never bool); invalid scalar/basket inputs return `None`, while an
invalid hedge returns `(0, 0)`.  There are no float tolerances, implicit
rounding allowances, residual overrides, or data-derived defaults.

## Boundary coverage and simplicity

Tests cover empty and malformed baskets; full contract identity mismatch,
root-only, unapproved-root, and non-quarterly IDs; bool quantities; nonpositive
multiplier/prices; non-Decimal and nonfinite values; negative costs; and
cross-contract endpoint changes.  Turnover covers empty and signed input plus
bool/float rejection.  The roll-boundary test passes only the old contract and
keeps its literal USD `13`; its causal control passes the altered new leg with
a USD-1 endpoint increase into the full basket and gets USD `2023` rather than
USD `23`.  Low caller precision is also tested for basket P&L and asserts the
entire configured caller Decimal context is unchanged after the call.

Ponytail full: this is two direct standard-library functions, one compiled
regex, existing `_decimal` validation, and the frozen fixture.  No dependency,
data/model class, registry, engine, file access, clock, calendar, tolerance,
source integration, z-score, state, network, broker, or order abstraction was
added.
