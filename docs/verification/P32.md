## Public contracts and exact policies

| API | Exact contract |
| --- | --- |
| `causal_zscore(current: SpreadObservation, prior: object) -> Decimal | None` | Exact 252-row, same-maturity, strictly increasing UTC history before current; sample standard deviation from prior gross excess only; local precision 50; zero variance and malformed input return `None`. |
| `signal_transition(prior_state: PositionState, z_score: Decimal | None, traditional_net_bps: Decimal, reverse_net_bps: Decimal, data_ready: bool, risk_flatten: bool) -> tuple[PositionState, tuple[str, ...]] | None` | Exact states, finite Decimals, and bools only; risk precedes unavailable data, then inclusive entry at `2.0`/`-2.0`, strict-positive directional nets, and `abs(z) <= 0.5` exit hysteresis. |
| `generate_signal_decision(decision_id: str, observation: SpreadObservation, prior: object, prior_state: PositionState, risk_flatten: bool, strategy_version: str, configuration_version: str) -> SignalDecision | None` | Recomputes the causal z-score; ready requires exact true quality/freshness, count `252`, and matching declared z-score. |
| `rank_opportunities(observations: object) -> tuple[str, ...] | None` | Non-string `Sequence` of exact synchronized unique-maturity observations; empty is `()`; malformed, duplicate-maturity, or timestamp-mismatched collections are `None`. |

Normal decision features, in order, are `z_score`,
`traditional_net_opportunity`, and `reverse_net_opportunity`. Unavailable-data
features are `observation_count`, `gross_excess_spread`, both directional nets,
and calculated `z_score` only when present. Risk flatten has no features.
Reason mappings are `risk_flatten`, `data_flatten`, ordered reversal actions
joined by `_then_`, `remain_flat`, `hold_traditional`, and `hold_reverse`; an
already-flat risk request maps to `risk_flatten_already_flat`.

Ranking excludes a row unless quality and freshness are exact true, count is
`252`, and z-score is non-null. Traditional eligibility is `z >= 2.0` with
traditional net `> 0`; reverse eligibility is `z <= -2.0` with reverse net
`> 0`. It first stable-sorts maturity text ascending, then stable-sorts
`z_score.copy_abs()` descending. This is the P32 provisional convention because
P10 omitted the promised score and tie-break; P10 did not freeze this rule.
